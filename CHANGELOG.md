# Changelog

All notable changes to Unick Auto Detailing are documented here.

---

## [1.0.0] — 2026-06-20

### 🎉 Initial Production Release

#### Added
- **Hero Section** — Cinematic landing with primary CTA
- **Services Grid** — 5+ detailing packages with pricing (`constants.tsx`)
- **Before/After Gallery** — Transformation visual showcase
- **AI Assistant** — Service recommendation engine with bundle psychology
- **6-Step Quote Wizard** (`QuoteForm.tsx`) — Multi-intent booking flow with real-time price estimation
- **How It Works** — Step-by-step process section
- **Service Deep Dives** — Per-service detail breakdowns
- **Service Areas** — Miami regional coverage map
- **Reviews Section** — Customer testimonials and star ratings
- **FAQ Section** — Accordion-style Q&A
- **Admin Dashboard** (`AdminDashboard.tsx`) — Password-protected lead management with status pipeline
- **Mobile Action Bar** — Persistent sticky CTA bar (call / WhatsApp / quote)
- **WhatsApp Integration** — Priority messaging shortcut throughout the app
- **Hash-based Routing** — `/#/admin`, `/#/quote` routes via React Router 7
- **Glassmorphism Design System** — Gold / Deep Space / Miami Cyan palette with `Outfit` + `Inter` fonts
- **Full mobile responsiveness** — Mobile-first layout across all breakpoints
- Deployed to Vercel: [unick-auto-detailing.vercel.app](https://unick-auto-detailing.vercel.app)
